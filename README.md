## Overview
Cyber-IP-Checker is a Python project that validates an IPv4 address, retrieves real-time information using a public REST API, generates a report, and saves the scan results to a file.

## Features
- Validate IPv4 addresses.
- Retrieve IP information from a public API.
- Display country, ISP, city, and scan time.
- Save scan reports automatically.
